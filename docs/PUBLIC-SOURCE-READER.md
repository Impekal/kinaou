# Explicit public-source reader (#415)

In Research → Source assessment, edit a retained observation and choose one of its original article links. **Retrieve source text** is explicit: selecting/opening the view never retrieves. Updated authenticated worker capability `public-source-reader` and POST `/research/source/read` accept only a bounded URL, never project text or credentials for the upstream site. The website sees the connection. No paid/cloud inference, account login, model, cookie jar, scripts, linked resources or browser automation is involved.

## Safety and extraction bounds

- Public HTTPS domain names on port 443 only; credentials, IP literals/aliases, local/reserved hostnames and invalid characters are refused. All DNS answers must satisfy conservative public-address checks; the chosen address is pinned while the original TLS hostname/certificate validation remain intact. Every redirect gets fresh validation and pinning, maximum three, without downgrade or loops. A separate nonpersistent agent avoids global proxy/session reuse.
- One active retrieval, at least five seconds between explicit attempts, no automatic retry/cache/stale fallback. Overall network deadline 20 seconds; headers 16 KiB; HTML 1 MiB; UTF-8 and uncompressed `text/html` only. Oversized/unsupported/denied pages fail explicitly. No paywall, anti-bot or login bypass. Original links remain available separately.
- MIT-licensed `parse5` 8.0.1 parses HTML inertly. Choose a unique `article`, otherwise unique `main`, otherwise `body`; omit active, navigation/form and explicitly hidden elements. This is not browser layout or reliable article identification: stylesheet-hidden, dynamic, related or promotional content may be missing or included. Display at most 30,000 characters, visibly mark truncation, and never claim full article completeness even when KINAOU did not shorten it.
- Show original/final URLs and redirects, retrieval time, original HTML byte count/SHA-256, page title, page-declared (unverified) language and extraction kind. A checksum identifies bytes, not signed provenance, source truth or media rights. Render plain text, never HTML. Source instructions remain untrusted data and are not sent to a model.

Network design uses documented [Node HTTPS requests](https://nodejs.org/docs/latest-v22.x/api/https.html), [custom lookup and address blocklists](https://nodejs.org/docs/latest-v22.x/api/net.html), conservative exclusions from the [IANA IPv4](https://www.iana.org/assignments/iana-ipv4-special-registry/) and [IPv6](https://www.iana.org/assignments/iana-ipv6-special-registry/) registries, and the [parse5 parse API](https://parse5.js.org/functions/parse5.parse.html), checked 2026-10-03. Conservative refusals may exclude otherwise legitimate sources.

## Temporary, read-only UI

Text stays only in the current reader, not project metadata, exports or a full-article archive. Internal Research tabs retain it, while closing the assessment/remounting/reloading discards it. Observed full-project/source/selected-link/connection/language changes permanently invalidate the session, including A→B→A; late results cannot revive. Explicit close discards a reply, not a claim that already-started upstream work was cancelled. No read checkbox, authored finding, note, project or safety version is changed by retrieval. Source review remains the creator's separate responsibility.
