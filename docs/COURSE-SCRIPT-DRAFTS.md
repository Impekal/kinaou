# Local lesson script drafts (#407)

In Course plan, select a saved lesson and expand **Local AI script draft**. Save/discard outline edits first. Enter your own authorized source notes (up to 12,000 characters), explicitly list installed local models, choose one and generate. An updated authenticated worker advertises `course-script` when local models are discoverable. No runtime/model installation, model download, cloud inference, automatic generation or narration occurs.

The model receives only source notes, course/lesson titles, course language, audience and lesson objective. It does not receive the whole project, other scripts, private answer keys, media paths, credentials or version history. Installed-model discovery plus `/api/show` metadata reject remote aliases and unknown architectures before sending authored text. Loopback HTTP, redirect refusal, bounded UTF-8 responses, strict schemas and exact source-substring checks constrain the request. They do not authenticate a malicious local runtime or prove teaching correctness.

## Explicit review and application

Each of one to twelve paragraphs contains spoken text (up to 1,500 characters) and a separate exact quote from the authored notes. Quotes never enter the accepted narration script automatically. They establish literal source presence only, not semantic entailment or truth. Inspect the previous script, edit every proposed paragraph as needed, review the final joined text and explicitly acknowledge content, language, sources and permission before replacement.

Only that lesson's saved script changes. Course revision advances normally; existing ranges, exercises, materials, other lessons, assets, timeline, main script and recordings remain intact. No time-fit or new speech-quality claim follows. Generated text needs meaningful instructor participation and review before use, including Udemy preparation; no automatic approval or publication is claimed.

An in-session capability binds the entire project/review. Observed project/dirty changes permanently invalidate it; UI/source/model/connection/language lifetimes reject stale replies and approvals even after A→B→A. Leaving/switching lesson loses unsaved proposals. A running local computation may finish, but its detached response is not applied. No automatic retries.

One exact prepared next project and one safety snapshot are reused if persistence fails. Retry saving the unchanged approved draft, not generation. Successful commit cannot be repeated with the same review. Source/original-model/accepted text, previous script, model, language and edited flag are retained privately under `courseScriptDrafts`. One latest record per course/lesson, up to 200 records and 4,000,000 UTF-8 bytes; corrupt/oversized data fails without eviction. Accepting another draft replaces that lesson's latest record, with prior project state in the safety version. This is historical attribution, not confirmation of later manual edits or a rendered video. Project/source archives are private; learner materials do not acquire this metadata automatically.
