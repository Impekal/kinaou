# Reviewed demonstration placement (#395)

Course → Production offers a saved-lesson/saved-demonstration selector. The demonstration must retain an exact available managed image/video reference (unique asset ID, unchanged URI/kind under `KINAOU/Assets/`). Other evidence types remain valid course records but are not silently converted to visual clips.

Enter lesson-relative start, display duration and video-source start in seconds (decimal point or comma, up to three decimals). Minimum duration is 250 ms. Images require source start zero; videos require a valid retained measured duration. Both lesson and source ends are hard bounds, not automatic trims, speed changes or lesson extensions. Retained metadata is not a fresh file inspection; use media availability checks separately.

Review displays the original lesson/demo titles, course revision, URI, absolute timeline interval and source excerpt. After explicit content/provenance/permission/timing acknowledgement, one ordinary new image/video track is saved. Video clip gain is zero, speed one. Existing active visual intervals on any visual track block insertion, including onto a new track; adjacent intervals and muted tracks do not. Narration, captions, other clips, original source files, course definitions and evidence records are unchanged. Normal Studio tools remain available for deliberate later editing and full playback/export review.

The ephemeral review is bound to the complete project, inputs, dirty-outline state and UI language, with observed A→B→A invalidation. It is not serializable/revivable. A persistence failure retries the same prepared project/clip IDs and one safety snapshot within the current view lifetime; no duplicate clip or file acquisition. Leaving discards this draft/review; no automatic retry after reload. History can restore prior project placement without deleting media. New system history labels also cover explainer-video saving in DE/EN/FR; arbitrary authored labels stay unchanged.
