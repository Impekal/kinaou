# Local curriculum drafts (#419)

Save a course (an empty outline is valid), then expand **Draft curriculum locally** in Course plan. Enter authorized source notes, select 1–6 new lessons, explicitly discover installed local models and generate. The adapter proposes 1–3 modules with the exact requested total. Edit titles/objectives, inspect original quotations, explicitly enter a planned start and time per lesson, review the complete additions and acknowledge before saving. Existing modules, lessons, scripts and media remain unchanged.

## Real adapter and boundaries

- Authenticated POST `/course/curriculum/generate`, capability `course-curriculum`, installed-model discovery and shared verified-local Ollama adapter. No download/cloud/remote alias, tools, retrieval or auto-generation. Only notes and saved title/language/audience/prerequisites/outcomes are model context, not old scripts, private answers, assets or history. Internal IDs/revision bind responses but are omitted from the prompt.
- Complete source JSON at most 12,000 UTF-8 bytes, complete prompt/schema at most 24,000 bytes, verified context at least 32,768 tokens, request context 32,768/output 4,096. Selected-model normal completion and token accounting are required; partial, oversized or malformed replies fail without silent shortening or repair.
- Strict bounded titles/objectives, nonempty exact source quotations, normalized duplicate-title rejection and exact lesson count. Quotes prove occurrence, not semantic support, truth, expertise or platform approval. Human content/language/pedagogy review remains required.
- Planned start/time inputs begin blank. They are authored consecutive timeline ranges, not model-invented or measured media lengths. Refuse overlap with existing lessons, duplicate existing titles, 24-hour bounds and ordinary course capacities (50 modules / 200 lessons). No clips/scripts/voice/captions are created. Reconcile ranges against actual production before export.
- One reviewed append, stable IDs, one revision and safety snapshot; failed persistence retries the exact prepared project without regeneration. Full-project/dirty/context/model/connection/UI-language lifetimes reject stale work including observed A→B→A. Timing/edit changes clear final review/acknowledgement. Leaving Course plan loses unfinished drafts and does not necessarily cancel already-started inference.
- Private `courseCurriculumDraft` stores only the latest accepted batch (200,000-byte cap): source preferences/notes, original/accepted proposals, model identity, edit flag, chosen planned ranges and generated stable IDs. Earlier additions stay in the outline and safety versions; historical provenance is not current quality approval. Saved reload does not generate anything.
